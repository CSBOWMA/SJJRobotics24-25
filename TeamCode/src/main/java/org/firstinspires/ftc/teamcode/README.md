## Team Code

here you can find the scripts ran during the competition and the [libraries](https://github.com/CSBOWMA/SJJRobotics24-25/tree/master/TeamCode/src/main/java/org/firstinspires/ftc/teamcode/libraries) created to assist in writing the autonomous and manual phases

## Scripts

Scripts ran during competition

### RobotClassAuto

Our autonomous script designed to score 48 points by placing three samples in the bucket during the 30 second autonomous period

### RobotSample

A manual script designed for two players to efficiently score samples during the 2 minute teleop period

Utilized color sensors on the front claw to correctly line up the claw with blocks for easier grabbing
The robot switches between different stages depending on the current goal, e.g. searching, passing the block, and scoring the block

### RobotSampleOne

Same functionality as RobotSample, but designed for only one driver

### RobotSpecimen

A manual script designed for two players to efficiently score specimens during the 2 minute teleop period

Relied on much of the same functionality as the sample script, but instead set the block to be hanged instead of placed in a bucket
