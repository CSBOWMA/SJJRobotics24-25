## robotPeripherals

This file contains the classes of each robot peripheral allowing for the user  to easily access and program any individual part of the robot.

## Elevator

The elevator consists of two DC motors and allows for the robot to place samples in high buckets.

## IntakeAngle

The intake angle is two servos that control what angle the front claw is at, i.e. should the intake claw be out and ready to grab, or in and ready to pass the block to outtake.

## IntakeClaw

The intake claw is a single servo that allows for the retrieval of samples.

## IntakePivot

The intake pivot is a servo that allows the claw to rotate parallel to the ground to align itself with samples.

## IntakeSlide

The intake slide consists of two servos and allows for the robot to reach out for blocks deep into the submersible.

## OuttakeAngle

The outtake angle is a single servo that control what angle the outtake claw is at allowing for the passing of samples, dropping of samples, and hanging of specimens.

## OuttakeClaw

The outtake claw is a single servo which grabs the block from the intake claw and sets up to place a block as needed.
